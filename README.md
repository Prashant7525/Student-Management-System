\# Student Management System



A beginner-to-intermediate Python project for managing student records, academic information, marks, and results.



\## Status



🚧 Under Development



\## Planned Features



\- Add students

\- View all students

\- Search students

\- View individual student details

\- Update student information

\- Delete students

\- Manage subject marks

\- Calculate total and average marks

\- Calculate grades

\- Input validation

\- JSON data persistence

\- Automated testing



\## Technologies



\- Python

\- JSON

\- pytest

\- Git

\- GitHub
